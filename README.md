# Python Utility Scripts

A small collection of Python examples and command-line utilities created in this workspace. The project contains calculator scripts, a command-line todo list, and a simple Blackjack/Betting demo.

## Project Contents

- `PythonCalculator.py` - Interactive command-line calculator with menu options for addition, subtraction, multiplication, division, modulus, and exponentiation.
- `calculator.py` - Another calculator script in the workspace. (Inspect this file for specific behavior and usage.)
- `Todo List (Command Line).py` - A command-line todo list utility.
- `year.py` - A small date/year related script or utility.
- `hello.py` - A basic introductory script.
- `math.py` - A file likely containing math helper logic or examples.
- `Folder item count.py` - A utility to count items in a folder.
- `blackjack/blackjack.py` - A simple betting and card game demonstration script.
- `blackjack/cards.py` - Additional card module used by the Blackjack demo.
- `IntroToPython.pdf` - Reference material or learning resource for Python.

## Getting Started

1. Make sure you have Python installed on your system.
2. Open a terminal in the project folder.
3. Run a script using:

```bash
python PythonCalculator.py
```

Replace the file name above with any other script you want to execute.

## Notes

- `PythonCalculator.py` uses integer-only input and currently does not handle division by zero.
- `blackjack/blackjack.py` includes a simple betting workflow and uses a separate `cards.py` module.
- This workspace appears to be a collection of small learning projects and practice scripts.
